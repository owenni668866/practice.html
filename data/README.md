# State data

- `california/` contains California Census tracts, PFAS monitoring sources, converted GeoJSON, and analysis output.
- `oregon/` contains Oregon PFAS sites and Census tract files. `washington-county-census-tracts.geojson` is Washington County, Oregon.
- `washington/` contains Washington State PFAS data.

Interactive HTML maps remain in the repository root and load their datasets from these folders.
